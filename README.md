# Power BI Sales Dashboard

This dashboard analyzes sales performance, profit trends, and regional KPIs.

## Features
- Sales trend analysis
- Regional performance tracking
- KPI cards
- Interactive filters

## Tools Used

- Excel
- DAX
- Power Query
